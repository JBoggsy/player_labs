# Emerg-ant user preferences

The root [`../user_preferences.md`](../user_preferences.md) also applies.

- **Never spend an experience request on self-play**. Experience
  requests consume a limited [credit allowance](../docs/xp-credits.md); users are not billed.
  The standing preference is to reserve that allowance for real-opponent evidence. Use a current real opponent in every Emerg-ant XP
  request unless James explicitly asks for self-play.
- Use the **James Botts** Coworld player account for Emerg-ant uploads and hosted
  evaluations. Verify the active player identity before any such
  operation; do not silently use or switch to Games Bond or another account.

When James states a durable preference specific to this game or lab, record it here;
do not infer preferences from one-off tactical directions.
