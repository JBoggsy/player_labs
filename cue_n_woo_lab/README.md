# cue_n_woo_lab

## The game

Cue-n-Woo is a two-player text game. Players interview a hidden-concept judge,
write challenge questions with their own answers, then answer the opponent's
questions. The judge compares answers using its hidden concept. The axis-combination
configuration selects values from independent axes; read
[the concept reference](docs/axis-combo-system.md) and the selected manifest.

Use [the lab guide](AGENTS.md), [gameplay](docs/cue-n-woo-gameplay.md), and
[mentalist_v4](mentalist_v4/README.md) for workflow, protocol and implementation.
