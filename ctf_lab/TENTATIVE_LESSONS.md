# Candidate guidance

- A replay viewer must derive geometry from the replay and reject missing map data.
  Confirm this invariant when sharing a viewer across generated and fixed maps.
- Build-cache keys must account for source and dependency changes, not merely the
  presence of an executable. Verify the binary used for each analysis.
- Resolve team colors from authoritative participant/configuration data. Slot parity
  does not define team membership in a multi-team game.

Promote a candidate only when independent evidence supports its intended scope.
